### Module 4 — what you'll actually be building

**Inputs you receive:** Device 1 vault, Device 1 ElGamal private key, Device 2 ElGamal public key, Device 1 ElGamal public key, shared DH params (q, α).

**Phases:**

1. **Key Exchange (signed DH):**
   - Both devices generate DH keypair (a, A=α^a mod q).
   - Device 1 sends `A` + ElGamal-sign(A) → Device 2 verifies the signature → aborts if invalid.
   - Device 2 sends `B` + ElGamal-sign(B) → Device 1 verifies → aborts if invalid.
   - Both compute shared secret `S = B^a = A^b mod q`.
   - Derive session key: `session_key = SHA-256(S)`.

2. **Transfer:**
   - Device 1 decrypts vault with master password's data key (calls Module 2).
   - Re-encrypts with `session_key` using AES-GCM.
   - Signs the session-encrypted blob with ElGamal private key (calls Module 3).
   - Sends `(encrypted_blob, signature)` to Device 2.
   - Device 2 verifies signature → aborts if invalid.

3. **Import (on Device 2):**
   - Decrypts with `session_key`.
   - User enters their master password.
   - Re-encrypts under new data key derived from new master password.
   - Signs with Device 2's ElGamal private key.
   - Stores locally.

**Hard constraints:**
- DH must be from scratch — using `cryptography` library = **zero on M4**.
- DH keys are ephemeral (fresh per export); ElGamal keys are long-lived.
- Both signatures must verify; either failure aborts the export.

### Hard rules (from spec) — reinforce with everyone

1. **DH and ElGamal must be from scratch** → external library use = zero on that module.
2. **AES and SHA-256 may be imported** (`pycryptodome` `AES.new(key, AES.MODE_GCM)`).
3. **No AI-generated code in submission** = zero on entire project. Use AI for explanation, planning, code review only — not to write the crypto/code that gets submitted.
4. **No copying between teams** = both teams get zero.

### Public API (this is the contract — write it first, fill in later)

```python
# Public DH parameters loading
def load_dh_params(path: str = "pwm/dh_params.json") -> tuple[int, int]:
    """Returns (q, alpha) where q is a large prime and alpha is a primitive root mod q."""

def generate_dh_params(bits: int = 2048) -> tuple[int, int]:
    """Generate a safe prime q and a primitive root alpha. Used once during setup."""

# DH keypair (ephemeral, per-session)
def generate_dh_keypair(q: int, alpha: int) -> tuple[int, int]:
    """Returns (private_a, public_A) where A = alpha^a mod q."""

def compute_shared_secret(other_public: int, my_private: int, q: int) -> int:
    """Returns shared secret S = other_public^my_private mod q."""

def derive_session_key(shared_secret: int) -> bytes:
    """Returns 32-byte AES-256 key = SHA-256(shared_secret_bytes)."""

# Export package format and flow
def build_export_package(
    vault_path: str,
    master_password: str,
    my_dh_priv: int,
    my_dh_pub: int,
    peer_dh_pub: int,
    my_elgamal_priv,            # type from Module 1
    my_elgamal_pub,              # included in package for verifier convenience
    q: int,
    alpha: int,
) -> dict:
    """
    Phase 2 (Transfer Phase) of the spec.
    Returns a JSON-serializable dict containing:
      - sender_dh_pub: int
      - sender_elgamal_pub_fingerprint: str (so receiver can match expected sender)
      - session_ciphertext_hex: str  (vault plaintext encrypted under session key, AES-GCM)
      - session_nonce_hex: str
      - session_tag_hex: str
      - signature_hex: str  (ElGamal signature over the session_ciphertext bytes)
    Raises ValueError if master_password is wrong.
    """

def consume_export_package(
    package: dict,
    my_dh_priv: int,
    peer_elgamal_pub,            # used to verify signature
    new_master_password: str,
    output_vault_path: str,
    my_elgamal_priv,             # used to re-sign new local vault
    q: int,
) -> None:
    """
    Phase 3 (Import Phase) of the spec.
    1. Verifies signature; raises SecurityError if invalid.
    2. Computes shared secret with peer_dh_pub from package.
    3. Decrypts session ciphertext to recover credential entries.
    4. Re-encrypts with new_master_password (Module 2).
    5. Re-signs new vault with my_elgamal_priv (Module 3).
    6. Writes to output_vault_path.
    """

# Signed DH public key exchange (Phase 1 — Key Exchange Phase of the spec)
def sign_dh_public(dh_public: int, elgamal_priv) -> bytes:
    """Wrapper that calls Module 3 sign() over int.to_bytes(dh_public, byteorder='big')."""

def verify_dh_public(dh_public: int, signature: bytes, elgamal_pub) -> bool:
    """Wrapper that calls Module 3 verify()."""
```

## CTF 4 — LSB Steganography Build Spec

### Target file: `ctf/ctf4_lsb_stego.py`

### Approach

LSB steganography hides data by replacing the least-significant bit of each color channel with one bit of the secret message. To recover:

1. Open `CTF_DATA/CTF4/stego.png` with Pillow.
2. Walk through pixels in row-major order.
3. For each pixel, take `r & 1`, `g & 1`, `b & 1` — that's 3 bits per pixel.
4. Concatenate bits into a stream.
5. Pack 8 bits at a time → bytes.
6. Decode bytes as ASCII / UTF-8.
7. Look for `CMPN{...}`, `FLAG{...}`, or readable text.

### Implementation skeleton

```python
from PIL import Image

STEGO_PATH = "CTF_DATA/CTF4/stego.png"

def extract_lsb_stream(path, channels=("R", "G", "B"), bit_order="msb"):
    img = Image.open(path).convert("RGB")
    pixels = list(img.getdata())
    bits = []
    channel_index = {"R": 0, "G": 1, "B": 2}
    for px in pixels:
        for ch in channels:
            bits.append(px[channel_index[ch]] & 1)
    return bits

def bits_to_bytes(bits, bit_order="msb"):
    out = bytearray()
    for i in range(0, len(bits) - 7, 8):
        b = 0
        if bit_order == "msb":
            for j in range(8):
                b = (b << 1) | bits[i + j]
        else:
            for j in range(8):
                b |= bits[i + j] << j
        out.append(b)
    return bytes(out)

def find_flag(data, max_preview=2000):
    text = data[:max_preview].decode("ascii", errors="replace")
    print(text)
    # Look for CMPN{ FLAG{ or other patterns
    for marker in (b"CMPN{", b"FLAG{"):
        idx = data.find(marker)
        if idx != -1:
            end = data.find(b"}", idx)
            return data[idx:end+1].decode()
    return None

def main():
    # Try permutations of channel order and bit order; print first plausible flag.
    for channels in [("R", "G", "B"), ("R",), ("G",), ("B",), ("B", "G", "R")]:
        for bit_order in ("msb", "lsb"):
            bits = extract_lsb_stream(STEGO_PATH, channels, bit_order)
            data = bits_to_bytes(bits, bit_order)
            flag = find_flag(data)
            if flag:
                print(f"FOUND with channels={channels}, bit_order={bit_order}: {flag}")
                return
    print("No flag found with simple permutations — try alpha channel or bitplanes.")

if __name__ == "__main__":
    main()
```
